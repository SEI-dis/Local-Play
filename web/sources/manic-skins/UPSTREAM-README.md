# ManicEMUSkins
Default skin for the Manic EMU emulator

### ㊟ PS.
The .manicskin file is essentially an unencrypted zip archive. If you want to study or modify it, just extract the .manicskin file.

### 📦 Skin Packaging Guide
Package your skin in three steps:
1. Place all assets **flat** (no parent folders)
2. Select all files and compress into a **non-encrypted ZIP** file
3. change extension to `.manicskin`
